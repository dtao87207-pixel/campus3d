# 浙大城市学院 · 三维校园空间模型

把校园（杭州湖州街 51 号，南校区 + 北校区）当作一个**可计算的空间系统**建模：
物理形态（建筑、路网、地面）、可达性（步行时间）、决策支持（服务点选址）。

成果是一个**单文件、离线可打开**的交互式三维页面，加一条可复算的数据管线。

![总览](out/fig4_views.png)

## 快速开始

```bash
python run_all.py            # 用已有缓存一键重建全部产物
python run_all.py --refetch  # 重新抓取 OSM 数据
```

只想要页面：直接双击 `out/campus_3d.html`。三角色库已内联，无需联网、无需服务器。

## 页面能做什么

- **视图预设**：总览 / 南校区 / 北校区 / 教学核心区 / 正视图；取景按窗口比例自动反解
- **要素开关**：地面底图、建筑体块、建筑名称、树木、日照阴影、选址点、等时圈
- **着色模式**：功能分类 / 层数 / 白模；层高倍数可调
- **日照**：太阳方位角与高度角滑杆，拖动即重烘焙建筑投影
- **步行可达性**：任选起点生成 3/5/8/10/15 min 等时圈
- **点击建筑**：层数、基底/建筑面积、估算高度、接入路网距离、最近 4 处设施步行时间、
  以及该楼在 OSM 名称与校方手绘地图名称之间的对照结论
- **保存 PNG / 重置视角**；也支持 URL 参数直接定位（见 `templates/campus_3d.html` 末尾）

## 方法要点

- **投影**：局部等距投影，原点 (30.32650, 120.15100)，单位米。
- **层数**：OSM 缺失层数按同类建筑中位数补齐（教学 6、实验 5、图书 5、行政 9、
  宿舍 7、餐饮 2、体育 3），数据里标记为估计值，页面点击时也会注明。
- **步行时间**：`t = 长度 / v(道路类型) + 过街惩罚`，速度 0.6–1.35 m/s，
  过街惩罚 6–12 s；建筑形心吸附到最近路网节点（容差 18 m，最远 220 m）。
- **可达性**：每栋楼做一次 Dijkstra，得 80 × 18 的时间矩阵。
- **选址**：在教学/图书/行政/实验类且有名称的建筑中穷举 4 处组合，
  最小化全校平均步行时间。
- **取景**：预设只记录方向与目标点，相机距离运行时把包围盒角点投影后二分反解。
- **楼名配准**：从手绘图量出 74 条标注的像素坐标，用 24 个已确定名的建筑拟合
  像素→平面坐标的仿射变换（剔除离群锚点后再用最近锚点残差做反距离加权补偿），
  残差中位约 23 m；据此确认 9 栋 OSM 无名建筑的身份，其余如实列为「无对应轮廓」。
- **阴影**：按太阳方向烘焙建筑投影贴图（Multiply），无 GPU 环境与普通浏览器表现一致。

## 2026-10 更新：地面用真实卫星影像

- `out/imagery_bbox.png`：Esri World Imagery 正射瓦片（z=18，238 张 256px 拼接，3584×4352，约 0.515 m/px），
  URL 形如 `https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/18/{ty}/{tx}`。
- `build_scene.py: ground_image_dataurl()` 把它压成 2048 宽 JPEG，以 data URL 写进 `out/scene.json`；
  前端 `buildGroundTexture()` 按 `groundImageRect` 把影像铺到 bbox 上，矢量图层以 16% 透明度叠加强化（不再重画路面，避免双层马路）。
- 配准验证见 `georef_check.py` → `out/step0_overlay_lib.jpg`：OSM 轮廓与影像重合误差 1–2 px。

> **本仓库不含原始影像瓦片与中间产物**（`out/imagery_*.png`、`out/step0_overlay_full.jpg`、
> `out/scene.json`，合计约 42 MB）。原因是 Esri World Imagery 的瓦片不随本项目再分发，
> 且 `scene.json` 的内容已内联进最终的 `campus_3d.html`。要复现这些中间文件：
> 按上面的 URL 模板自行下载 238 张 z=18 瓦片拼成 `out/imagery_bbox.png`（3584×4352），
> 再跑 `build_scene.py`。最终 HTML 已包含处理后的影像，不重建中间产物也能直接打开。

## 影像描边的尝试记录（未采用）

`extract_from_imagery.py`（全局屋顶分割）、`trace_missing.py`（按配准预测位置开窗口描边）是本轮对「OSM 缺轮廓的 17 栋」的自动提取尝试，
四种方案（固定阈值 / 颜色高斯混合 / 局部连通域 / 多种子区域生长）均只能出碎片，未纳入模型。结论见报告「七附」。
